# OpenCode Serve - chat bot

設一個 chat bot , 它可以連接 opencode serve API, API 功能包含：
- 建立/切換 專案目錄
- CRUD、Rename會話(session)
- 查詢 session 並進入接續 session
- Agent 供應商及模型設定

Menu 頁建立全新父層, App 名稱即為專案 , Agent Server 管理, 可指定後端的 opencode serv, 建立App
