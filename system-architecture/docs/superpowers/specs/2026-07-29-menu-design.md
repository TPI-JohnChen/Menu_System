## 設計摘要

為 OrientAI（單機 AI Agent，建構於 Opencode 引擎之上）設計完整的 Menu 功能結構，目標使用者為 OrientAI_Manager 管理員，使用情境為 5人/工作室多種 Agent 共存。

### 主要涵蓋

1. **Menu 結構**：9 個一級選單，完整功能描述
2. **RBAC 權限模型**：4 固定角色 + 自訂角色，扁平部門，部門管理員可自治
3. **部門結構決策**：扁平 vs 樹狀分析
4. **混合角色模型**：固定 + 自訂
5. **效能監控架構**：TTFT/TOPS 比對
6. **SOP 任務拆解與 Agentic Workflow**：四步驟方法論
7. **稽核日誌**：設定變更 + 對話往返

### RBAC 角色定義

| 角色 | 跨部門資源 | 所屬部門資源 | 特殊權限 |
|:----|:----------:|:------------:|:--------|
| **系統管理員** | 全部 CUD | 全部 CUD | 可管理全部部門與使用者、修改角色定義 |
| **部門管理員** | 全部 R | 部門資源 CUD | 可自治部門，可指定一名代理人 |
| **部門代理人** | 全部 R | 部門資源 CUD（代理期間） | 由部門管理員指定 |
| **部門成員** | 全部 R | 部門資源 R | 個人任務 CUD |

### 開發順序（4 Phase）

| Phase | 功能 | 預計交付 |
|:----:|:----|:--------:|
| 1 | Agent Server 管理 → Provider 設定 → 快速對話/Agent 對話 → App CRUD | MVP |
| 2 | Skill 管理/上傳/日誌 → RBAC → 外部 Agent | v1 |
| 3 | 定時任務 → 儀表板 → 稽核日誌 | v2 |
| 4 | SOP 工作流 → 效能面板 → Import/Export → 自訂角色 | v3 |

## 設計決策記錄

| 決策 | 選項 | 理由 |
|:----|:----|:-----|
| 部門結構 | 扁平 | 簡單直覺，5人工作室 over-engineering |
| 角色模型 | 固定 4 個 + 自訂 | 保有簡單又具彈性 |
| 代理人 | 非獨立角色，為 Dept Admin 屬性 | 避免角色爆炸 |
| 對話入口 | 快速對話（個人預設）+ Agent 對話（完整 Chat Bot） | 分別滿足快速與進階需求 |
| App 來源 | CRUD 管理 + 預設 3 個 | 可擴充的獨立 HTML 頁面 |
| MCP 管理 | 不在 Menu 中 | MCP 是 Opencode 內部事項 |
| Marketplace | 全刪 | 屬於 OrientAI_Manager 功能 |
